# Program Pertamaku – Flutter

## 📝 Deskripsi Singkat

Aplikasi sederhana berbasis Flutter yang menampilkan nama **Karina Eka Septiana** di tengah layar dengan ukuran teks 24. Aplikasi ini dibuat sebagai latihan dasar untuk memahami struktur program Flutter dan penggunaan widget untuk membangun antarmuka aplikasi.

## ✨ Fitur Utama

- Menampilkan judul aplikasi **Program Pertamaku** pada AppBar.
- Menampilkan nama Karina Eka Septiana di tengah layar.
- Mengatur ukuran teks menggunakan `TextStyle`.
- Menggunakan widget `Center` untuk memposisikan teks di tengah layar.
- Menggunakan widget `Scaffold` sebagai struktur dasar halaman aplikasi.

## 🛠️ Teknologi dan Package

- **Flutter** – Framework untuk membangun antarmuka aplikasi.
- **Dart** – Bahasa pemrograman yang digunakan.
- **Material Design** – Menggunakan widget bawaan dari package `flutter/material.dart`.

Aplikasi ini tidak memerlukan package tambahan.

## 🚀 Langkah Menjalankan Aplikasi

1. Pastikan Flutter SDK dan Android Studio atau Visual Studio Code sudah terpasang.

2. Clone repositori GitHub atau buka folder proyek Flutter.

3. Buka terminal pada folder proyek.

4. Jalankan perintah berikut untuk mengunduh dependensi:

   ```bash
   flutter pub get
   ```

5. Jalankan aplikasi menggunakan perintah:

   ```bash
   flutter run
   ```

6. Pastikan emulator Android atau perangkat yang terhubung sudah siap digunakan.

## 📚 Tujuan Pembelajaran

Melalui aplikasi ini, pengguna dapat mempelajari struktur dasar aplikasi Flutter, penggunaan widget `MaterialApp`, `Scaffold`, `AppBar`, `Center`, dan `Text`, serta cara mengatur ukuran teks menggunakan `TextStyle`.
